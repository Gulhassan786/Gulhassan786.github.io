Final Year Project · Deep Learning

AI-Based Acoustic Recognition System for Avian Species

Wildlife surveys still rely on manual audio tagging — slow and inconsistent. I built an end-to-end classifier where librosa mel-spectrograms feed a custom 6-layer CNN (16–1024 filters), served through a Flask interface for real-time classification.

Reached 80% test accuracy across species on held-out audio.
CNNLibrosaFlaskPython

Deep Learning

Emotion Recognition from EEG Signals

Emotion detection from brain signals is noisy and usually needs hand-crafted features. I trained an LSTM pipeline directly on EEG sequences with an adaptive learning-rate scheduler, then validated it against a confusion matrix and F1-score.

98.2% test accuracy with balanced per-class F1.
LSTMTensorFlowScikit-learn
GitHub
Transfer Learning

Automated Brain Tumor Detection Using MRI Scans

Early tumor diagnosis is limited by radiologist time. I fine-tuned EfficientNetB0 via transfer learning on a Kaggle MRI dataset with OpenCV preprocessing to classify scans automatically.

98% test accuracy, validated with precision, recall, and F1.
EfficientNetB0OpenCVTensorFlow
GitHub
NLP

Sentiment Classification with Computational Linguistics

Rather than assume a model, I benchmarked five algorithms on an NLP preprocessing pipeline (NLTK + TF-IDF) to find the most reliable text classifier, then shipped the winner as a live app.

SVM won with a 0.89 F1-score; deployed on Streamlit.
SVMNLTKStreamlit
